What is Jenkins?

Jenkins is a self-contained, open-source automation server that can be used to automate all sorts of tasks related to building, testing, and delivering or deploying software.

Continuous Integration (CI)

Automatically build and test code changes every time a developer commits to version control, catching bugs early.

Continuous Delivery (CD)

Automate the release process so that tested code can be deployed to staging or production environments seamlessly.

Extensible Ecosystem

With hundreds of plugins available in the Jenkins update center, it integrates with practically every tool in the CI/CD toolchain.
